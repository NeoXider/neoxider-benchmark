Tokens → score

X axis — net tokens (tokens_net), Y axis — final score. Each point is labeled.

Cost → score

X axis — run cost, Y axis — score. A free tier is not a free model: the open weights behind it carry a public market rate, so cost is computed from the measured tokens at that rate and marked with a ~. Where the CLI reports a real charge it is used as-is. A rate of zero is never treated as a price — it would pin the run to the axis and make any quality look infinitely efficient. Unpriced runs are listed below the chart.
